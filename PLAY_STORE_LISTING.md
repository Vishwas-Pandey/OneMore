## Full description (max 4000 characters)

```
One More is a minimalist one-tap arcade game about fast reactions and one more try.

Tap to jump. Time it right, keep going, and watch the pace pick up the longer you survive. Miss, and you're back at the start — with your best score staring you down, daring you to beat it.

HOW TO PLAY
- One tap, anywhere on screen, to jump.
- Obstacles come faster the longer you survive.
- Beat your own best score. That's the whole game.

FEATURES
- Simple one-tap controls anyone can pick up in seconds
- Fast, escalating difficulty that rewards focus and timing
- Local high score tracking, so every run is a chance to beat yourself
- Sound, music, and haptic feedback you can toggle independently
- Optional rewarded video to continue a run in progress
- Plays fully offline

One More doesn't ask much of you: just one tap, and the will to try again.
```

(Word this is intentionally plain and literal — no superlative claims, since none of the "avoid" items below are true of this app and shouldn't be implied.)

## What this listing deliberately avoids, and why

Per the explicit instruction not to make unsupported or misleading claims:
- No "#1 game" / ranking claims — not evaluated against any ranking, so not claimed.
- No "most addictive" / compulsion-framed language — avoided regardless of genre norms.
- No monetization claims beyond what's true — the listing does not say "free" without qualification if ads/IAP exist, and does not promise ad-free play; it only says a rewarded video is "optional," which is accurate per the actual AdManager implementation (Continue is offered, never forced, and the game is fully playable without ever watching an ad — you just don't get a continue).
- No claims about install counts, ratings, or awards the app does not actually have.
